## Bluesky Arash Project 

This is a project that was intended to clone the bluesky app and implement arash functionality for video verification. At the end of this project ive only managed to make the bluesky clone with some code remnants of the attempt to implement arash into the application. 

## How to use 

### From bluesky-arash/backend run: 

python -m uvicorn main:app --reload

### And then from bluesky-arash/frontend run:

npm run dev 

### You can now access the app using the link provided after "npm run dev"
